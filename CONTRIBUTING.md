# Contributing to Moonshot

Thank you for your interest in improving Moonshot!

## Development Guidelines

1. **Safety & Privacy:** Moonshot is offline-first. Never introduce tracking, analytics, or background daemons.
2. **Platform Native:** Target the Omarchy shell with standard Quickshell QML and pure Python ephemeris calculation.
3. **Astronomy Accuracy:** All astronomical calculations rely on vendored Astronomy Engine and validated golden fixtures.
4. **Validation:** Run `make validate-plugin` and `make test` before submitting changes.

## Reporting Issues

Use GitHub Issues to report bugs or request features. Include details about your Omarchy version, Quickshell version, and screen resolution.
